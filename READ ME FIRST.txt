SSES CMMS - SAMPLE FOR TESTING
==============================

This is a test copy of the SSES maintenance management system (CMMS).
It runs only on this computer, with made-up demo data. Nothing you do here
affects the real system, and you can't break anything.

HOW TO START
1. Unzip the whole folder somewhere, e.g. your Desktop (don't run it from inside the zip).
2. Double-click "Start SSES CMMS sample.cmd".
   If Windows shows "Windows protected your PC", click "More info" then "Run anyway".
3. Your browser opens http://localhost:5090. If it doesn't, open that address yourself.
4. Keep the black window open while testing. Close it to stop.
